# Akbar Mujahid portfolio

A dependency-free static first pass. Open `index.html` in a browser or serve this folder with any static host.

## Before publishing

- Replace `hello@example.com` in `index.html` with the preferred contact email.
- Replace the UI studies marked `Interface study — replace with product capture` with real project screenshots or recordings.
- Add verified project and social links when available.

The site uses only documented project facts supplied for ResQTrack, Re-Source, ClipFetch, VerbaSense, and HandSpace. The interface studies are deliberately visual placeholders, not claims about the shipped UI.
